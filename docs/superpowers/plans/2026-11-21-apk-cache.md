# APK dell'aggiornamento: riuso, attesa del rientro e pulizia — piano

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** riusare l'APK già scaricato, aprire l'installer solo con l'app in primo piano, pulire la cache.

**Architecture:** download in `.part` rinominato a fine download; funzione pura `staleApkNames` decide
cosa cancellare; `cleanupApks` all'avvio a freddo; attesa di `AppState` `active` prima dell'installer.

**Tech Stack:** Expo 57, `expo-file-system` (`File`, `Directory`, `Paths`), React Native `AppState`, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-21-apk-cache-design.md`

## Global Constraints
- Nessuna dipendenza nuova. Nomi file: `CusCosenza-<X.Y.Z>.apk`, temporaneo `CusCosenza-<X.Y.Z>.apk.part`, in `Paths.cache`.
- La pulizia non deve mai lanciare eccezioni verso l'app; avviene solo al montaggio di `UpdatePrompt`.
- Popup sempre con `AppDialog`. Conventional Commits (`fix:`), branch `fix/cache-apk-aggiornamento` da `master`.

## Review Focus
- Versione installata non valida → si cancellano solo i `.part`, mai gli `.apk` (test in Task 1).
- File in cache non nostri (altri nomi) → mai toccati (test in Task 1).
- Ritorno in primo piano durante un download → il `.part` in scrittura non viene cancellato (pulizia solo al montaggio, Task 2).
- Installer annullato → pulsante "Installa", ripremuto non riscarica (Task 2, verifica a mano).
- Download finito con app in background → installer aperto al rientro, nessun "Download o installazione non riusciti" (Task 2, verifica a mano).

### Task 1: scelta dei file da cancellare

**Files:** Modify `src/services/updateRelease.ts`; Test `src/services/updateRelease.test.mjs`

**Interfaces:** Produces `export function staleApkNames(names: string[], currentVersion: string): string[]`.

- [ ] **Step 1: test che falliscono**

```js
test('staleApkNames cancella .part e APK di versioni già installate, nient altro', () => {
  const names = ['CusCosenza-2.8.3.apk', 'CusCosenza-2.8.4.apk', 'CusCosenza-2.8.5.apk',
    'CusCosenza-2.8.5.apk.part', 'altro.txt', 'CusCosenza-latest.apk'];
  assert.deepEqual(staleApkNames(names, '2.8.4'),
    ['CusCosenza-2.8.3.apk', 'CusCosenza-2.8.4.apk', 'CusCosenza-2.8.5.apk.part']);
});

test('staleApkNames con versione installata non valida cancella solo i .part', () => {
  assert.deepEqual(staleApkNames(['CusCosenza-2.8.3.apk', 'CusCosenza-2.8.3.apk.part'], 'boh'),
    ['CusCosenza-2.8.3.apk.part']);
});
```

- [ ] **Step 2:** `npm test` → FAIL (export mancante).
- [ ] **Step 3:** implementare con una regex `^CusCosenza-(\d+\.\d+\.\d+)\.apk(\.part)?$`; `.apk` cancellato solo se
  `parseVersion(currentVersion)` è valido e `!isNewer(versione, currentVersion)`.
- [ ] **Step 4:** `npm test` → PASS; `npx tsc --noEmit` pulito.
